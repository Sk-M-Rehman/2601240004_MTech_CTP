The Student Attendance Management System is a Python program designed to store and analyze students' attendance records. The program allows the user to enter details for multiple students, including their Student ID, Name, Total Classes Conducted, and Classes Attended.

For each student, the program calculates the attendance percentage using the formula:

Attendance Percentage = (Classes Attended / Total Classes Conducted) × 100

The student information is stored using Python dictionaries, and all student records are maintained in a list.

Main features of the program:
Accepts attendance details for multiple students.
Calculates each student's attendance percentage.
Displays the complete attendance details of all students.
Identifies students whose attendance is below 75%.
Finds the student with the highest attendance percentage.
Calculates the average attendance percentage of the whole class.

This program demonstrates the use of important Python concepts such as lists, dictionaries, loops, conditional statements, arithmetic operations, and user input/output. It can be useful as a basic system for managing and analyzing student attendance in a class.
